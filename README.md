## Sobre o projeto

Meu projeto individual ainda não possui um nome, mas seu tema está bem consolidado. A confecção de objetos, quaisquer que sejam, por exemplo: cerâmicas, origamis e caseiras, é uma forma de passar o tempo e desenvolver novas habilidades de maneira agradável e recompensadora. Além disso, essas atividades estimulam a criatividade, a concentração e a capacidade de resolver problemas, permitindo que cada pessoa explore seus interesses e transforme ideias em criações concretas.


## Tecnologias e Ferramentas Utilizadas

- JavaScript
- HTML5
- CSS
- VS Code
- Figma / Canva
- Trello / Word
- Criatividade :)
